Guida alla Pubblicazione Online Gratis

Rendi questa app accessibile agli studenti dal loro smartphone

Per fare in modo che gli studenti possano interagire simultaneamente dai propri dispositivi, pubblica gratuitamente questo singolo file HTML usando uno dei seguenti servizi:

1. Netlify Drop (Scelta più rapida) Consigliato

Salva questo codice come file index.html, trascina la cartella che lo contiene su app.netlify.com/drop e ottieni subito un link pubblico.

2. Vercel o GitHub Pages

Puoi caricare il file su un repository GitHub e attivare GitHub Pages dalle impostazioni, oppure collegarlo a Vercel per un deployment immediato.

Sincronizzazione Cloud Firebase

L'applicazione include il supporto automatico per la sincronizzazione tramite Firebase Firestore. Se viene caricata senza chiavi personalizzate, utilizzerà un salvataggio in memoria locale (LocalStorage) con aggancio al database.
